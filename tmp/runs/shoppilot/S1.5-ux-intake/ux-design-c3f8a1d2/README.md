# ShopPilot — UX-design Intake Pack (v1.1)

Generated by `generate-ux-pack 0.1.0` (S1.5 `ux-intake`) from the **BA brief only**. No UX-team drop
(frontend spec / prototype HTML) was available for this run, so brand, visual and Thai-microcopy
fields are honestly marked `TBD-*` and surfaced as findings rather than invented.

## Navigation

| File | What it is |
|---|---|
| `tokens.json` | W3C design tokens — semantic/spacing/typography/radius derived; **brand = TBD** |
| `route-map.md` | route → screen → BA story map (+ gaps) |
| `component-inventory.md` | atoms/composites with a11y annotations |
| `microcopy.json` | bilingual TH/EN strings — `en` derived from BA acceptance criteria, `th` = TBD |
| `screen-states.md` | per-route idle/empty/loading/error/success/auth states |
| `form-validation.md` | per-form rules, Thai-locale + banking carve-outs |
| `responsive-spec.md` | breakpoints, touch targets, safe-area |
| `accessibility-spec.md` | WCAG AA: contrast, focus order, SR announcements |
| `flows/` | 4 customer journeys (Mermaid) |
| `screens/` | per customer-facing epic: EPIC.md + per-story screens |

## Derived vs TBD

**Derived from the BA brief (real):** routes, screen inventory, screen states, the 4 customer flows,
English microcopy lifted from acceptance criteria, form rules, accessibility structure, semantic-color
contrast (computed).

**TBD — needs the UX-team drop (P1/P2 findings in `../output.json`):** brand color tokens, all Thai
microcopy, prototype URL, Figma URL, UX-team contact, desktop-responsive intent, component visual specs.

## Coverage

- **Customer-facing epics with screens:** EPIC-AUTH, EPIC-CHECKOUT, EPIC-ORDER (story ORDER-01).
- **Back-office / internal (no customer UX, by design):** STORY-ORDER-02 (admin fulfillment),
  STORY-INVENTORY-01 (system reservation), STORY-INVENTORY-02 (admin stock) — listed under
  `ba_stories_without_ux_coverage` as intentional internal scope, not gaps.
